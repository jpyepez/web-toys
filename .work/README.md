# .work/

Local work-tracking for this project. Maintained by the engineering skills
(`/grill-with-context`, `/draft-prd`, `/draft-issues`, etc.).

- `CONTEXT.md` — domain glossary (what the words mean)
- `adr/` — architectural decision records (what the system is built around)
- `out-of-scope/` — deliberately rejected features (what the system won't become)
- `prds/` — product requirement docs
- `issues/` — work items (`issues/bugs/` for defects)
- `notes/` — scratch space (gitignored)
